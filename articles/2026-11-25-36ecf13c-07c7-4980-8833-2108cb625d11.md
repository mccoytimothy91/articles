# 勋章主题切换只改 CSS 变量不动结构

<!-- content-workspace-job:36ecf13c-07c7-4980-8833-2108cb625d11 -->

## 问题场景

勋章后台要支持深浅两套主题，原先每个组件都写死了颜色，改一次要动几十个文件。

## 实现步骤

在根选择器上定义颜色变量，组件样式一律引用变量而不是字面值。

```css
:root {
  --bg: #ffffff;
  --fg: #1f2328;
  --line: #d8dee4;
}
:root[data-theme="dark"] {
  --bg: #16181d;
  --fg: #e6edf3;
  --line: #30363d;
}
```

切换主题时只改根节点的类名，由类名覆盖变量取值。

```javascript
.card {
  background: var(--bg);
  color: var(--fg);
  border: 1px solid var(--line);
  padding: 12px 16px;
}
```

把选择结果写入本地存储，刷新后先读回再渲染，避免闪白。

```javascript
const root = document.documentElement;
function apply(mode) {
  root.dataset.theme = mode;
  localStorage.setItem('badge-theme', mode);
}
```

## 注意事项

变量要定义在包含所有组件的作用域上，写在组件内部无法被全局覆盖；内联样式优先级更高，会盖掉变量。

如果数据量继续增长，需要评估对现有调用方的影响面，并同步给相关方知会。

结合历史事故记录，要把异常路径和正常路径分别覆盖一遍，确认指标平稳后再逐步放开。

在迁移过程中，可以通过压测确认容量水位，之后再考虑扩大适用范围。

在实际落地时，应确认依赖版本与运行环境一致，降低同类问题再次发生的概率。
