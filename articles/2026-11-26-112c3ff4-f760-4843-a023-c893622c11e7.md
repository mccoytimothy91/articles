# 税率推送用 SSE 并在断线后自动重连

<!-- content-workspace-job:112c3ff4-f760-4843-a023-c893622c11e7 -->

## 问题场景

税率状态需要近实时更新，轮询开销大且延迟高，直接用长连接又容易在弱网下静默断开。

## 实现步骤

用 EventSource 订阅推送地址，监听 message 事件更新状态。

```javascript
function connect(url, onData) {
  let delay = 1000;
  const open = () => {
    const es = new EventSource(url);
    es.onmessage = (e) => { delay = 1000; onData(JSON.parse(e.data)); };
    es.onerror = () => { es.close(); setTimeout(open, delay); delay = Math.min(delay * 2, 30000); };
    return es;
  };
  return open();
}
```

监听 error，在连接关闭后按递增间隔重建，避免密集重试。

```javascript
const state = { count: 0 };
const es = connect('/api/tax/stream', (msg) => {
  state.count += 1;
  document.querySelector('#tax-badge').textContent = state.count;
});
```

## 注意事项

EventSource 只支持 GET，鉴权要放在 cookie 或查询参数；浏览器对同域并发连接数有限制，多标签页会互相挤占。

从排障效率看，应定期回顾相关监控指标，以便后续复盘有据可查。

遇到复杂链路时，先把最小可复现的用例固定下来，让排查路径更短。

结合历史事故记录，要把边界条件列成清单逐项确认，让容量规划更有依据。

针对这类偶发问题，尽量把决策依据写进变更说明，并保留回滚开关以便快速恢复。

在跨团队协作时，要避免在高峰期执行这类操作，使运维成本保持在合理区间。

在资源受限的环境下，要避免在高峰期执行这类操作，同时把结论沉淀进团队文档。
